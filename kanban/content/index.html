OTOBO Kanban Board¶

Description¶

The Kanban Board in OTOBO is a powerful visual tool designed to help teams manage and optimize their workflows effectively. It provides a clear and intuitive interface for tracking the progress of tasks, tickets, or issues in real-time, ensuring that team members are aligned and work is flowing smoothly from start to finish.

  • Visual Workflow Management: The board provides a visual representation of tasks, allowing users to easily see which tasks are in progress, completed, or pending.

  • Customizable Columns: Define and customize the columns to match the specific stages of your team’s workflow.

  • Drag and Drop Functionality: Easily move cards from one column to another by dragging and dropping, simplifying task updates.

  • Card Details and Comments: Click on any card to view detailed information, add comments, or attach files, enhancing collaboration.

  • Real-Time Updates: All changes made to the Kanban Board are instantly updated for all team members, ensuring transparency and up-to-date information.

  • Filtering and Search Options: Use advanced filters and search options to quickly find specific cards or tasks.

Usage¶

To get the most out of your Kanban Board, the following requirements must be met:

Note

  • OTOBO must be installed: Ensure that OTOBO is installed.

  • How To - Package Manager

  • Agents must be created: Ensure that all relevant agents have been set up in the system.

  • Groups must be established: Define and create the necessary groups for organization.

  • Agents must be assigned to groups: Make sure each agent is properly assigned to the appropriate group.

  • A customer must be created: Register the necessary customer in the system.

  • A customer user must be created: Set up a user account for the customer to enable access.

  • Processes must be created or already exist in order to create a Process Kanban Board.

  • Dynamic Fields must be created or already exist in order to create a Dynamic Field Kanban Board.

By ensuring these steps are completed beforehand, you can seamlessly implement and operate the Kanban Board.

Admin Guide¶

This guide provides a step-by-step instruction on how to configure and manage Kanban Boards after successfully installing the Kanban module using the package manager.

Accessing Kanban Board Management¶

To access the Kanban Board Management interface:

  1. Navigate to the Admin area located in the top-left corner of the navigation bar and select Overview.

  1. You can either search for “Kanban” using the search function in the top left or find the tile under “Miscellaneous”.

Kanban Board Management Interface¶

In the Kanban Board Management interface, you have the following options:

  • Create new boards

  • Manage existing boards

  • Arrange the order of Kanban Boards via drag and drop.

Click on Add Kanban Board to create your first Kanban Board.

General Settings¶

Under the General menu, you can configure the basic settings for your first Kanban Board.

  • Board: The configuration begins by entering the Board Name.

  • Board Type: You have the option to choose from different board types. Special Note: If the board type “Processes” is selected, the list will expand to show a selection field with your existing processes.

Note

For the board type Processes, the processes must also be defined, which are then displayed under the board type selection - as soon as the board type Processes is selected. The activities associated with the process are then available as columns.

  • Groups: You can define which users have access to the Kanban Board. Note that the group “Kanban” is required for permissions to the Kanban module. Further access control can be managed through additional groups.

  • Validity: Use this option to activate, deactivate, or temporarily lock boards.

Sorting Options¶

Sorting allows you to configure the Kanban Board according to the desired criteria.

  • You can define the order as ascending or descending.

  • Standard Sorting by State Type: Allows you to further filter options based on the ticket state.

  • Ticket Display Options: You can choose to display all tickets, only archived, or only non-archived tickets.

  • Standard Filter “Owner”: Allows you to create boards assigned to you. Save the created board by clicking on the Save button.

Completing Board Configuration¶

  • After creating your first board, select your board to proceed with further settings by clicking on the boards name.

  • If you have already clicked on the Kanban icon in the navigation bar, you will be notified about the missing configuration.

Column Configuration¶

Under the Columns menu:

  1. You can change the board type again via the board type selection.

  2. Use the search function to filter columns.

  3. Select / de-select all columns at once using the square brackets.

  • Select a single column using drag & drop and place them in the order you want them to be displayed on the kanban board. After making your selection, make sure to click Save.

Note

If you select dynamic fields as the board type, you must also select a dynamic field whose selection options can then be configured as columns. This is done via a drop-down menu which appears above the drag & drop area.

Swimlanes Configuration¶

Swimlanes are divided into three categories: Priority, Owner, and Queue, each with corresponding selection options.

Changing the category results in the associated swimlanes being loaded.

Note

  • If no specific swimlanes are defined, all tickets are displayed in one large lane.

Quick Filters¶

Use Quick Filters to create custom filters that are easily accessible right on your board.

To create a new filter:

  1. Click on New Filter.

  1. Choose a name, describe your filter, and use your desired filter query.

Note

Filters are defined as a chained string of key-value pairs.

Example:

Queue=Junk,Postmaster,Raw

or:

State=new;Priority=3 normal

Negation is also supported.

Example:

Queue=Junk,Postmaster,Raw

or:

State!=new;Priority!= 5 very high

Everything can be combined.

Example:

Queue=Misc,Junk;Priority!=3 normal

Available filters:

- State
- Queue
- Priority
- Type
- Service Type
- SLA

For own tickets:

Owner=Self,LoginName,OtherLoginName,...

Dynamic fields:

DynamicField_Name=Value1,Value2,...

Wildcard support:

(*Value1*, *Value2, Value3*)

A wildcard must always be used for dynamic fields with a multiple selection in order to obtain correct results:

DynamicField_MultipleSelect=*Value1*,*Value2*

You can also adjust the order of the quick filters displayed on the board using drag and drop. Make sure to click Save after making changes.

Board Links¶

The Board Links menu allows you to create custom buttons with links to keep all necessary functions just a click away.

  1. Predefined link quick selection

  • Click on one of the icons to create a predefined link

  1. Board Link Configuration

Tip

Board Links Information:

  • Board links are defined by an action, and optionally, a parameter (sub-action).

  • Example of an internal link: /otobo/index.pl?Action=AdminAppointmentCalendarManage;Subaction=Overview.

  • Extract from your desired link, as in this example, the Action “AdminAppointmentCalendarManage” and the Subaction as parameter “Overview”. Then mark the “internal” field to create a personalized link.

  • For an external link, such as to Google Search, use “www.google.de” as the Action and “webhp” as the Parameter. The “Internal” field remains unmarked since it is an external request. The link will be created as follows: https://www.google.de/webhp.

3. Board Link Icon Configuration - You can flexibly configure your own icons by using Font-Awesome 4 Icons.

You can also adjust the order of the board links displayed on the board using drag and drop. Make sure to click Save after making changes.

Note

Board Link System Configuration

In the System Configuration - Kanban - BoardLinkIcons, you also have the option to customize the default board link colors, default board link icons, and default button text colors according to your preferences. For more details, refer to System Configuration - Board Links.

System Configuration - Kanban Settings¶

You can set selectable dynamic fields for cards, such as “DynamicField_Name”.

Set the default sorting criteria for new boards. Supported sorting fields include:

  • Created

  • Owner

  • Responsible

  • CustomerID

  • State

  • TicketNumber

  • Queue

  • Priority

  • Age

  • Type

  • Lock

  • Changed

  • Title

  • Service

  • SLA

  • PendingTime

  • EscalationTime

  • EscalationUpdateTime

  • EscalationResponseTime

  • EscalationSolutionTime

  • Supported order: ascending | descending.

Set the secondary sorting criteria for new boards. Supported sorting fields and orders are the same as for the primary sorting.

Configure the caching time for boards in minutes.
  • Examples:

    • 60 = 1 hour

    • 720 = 12 hours

    • 1440 = 1 day

    • 0 = caching deactivated

Set the maximum number of cards that can be displayed on a board.

Set the default time in minutes for tickets moved to the pending reminder state.
  • Example:

    • 7 * 24 * 60 for one week

    • 1440 for one day (default setting).

Configure a dynamic field of type “SingleSelect” to filter tickets based on selectable values.

KanbanTags - Visual Tag Management¶

The KanbanTags feature provides a visual tag management system that allows users to categorize and organize tickets directly on the Kanban board using colorful badge-style tags. This feature is implemented as a custom Dynamic Field type that integrates seamlessly with the Kanban board interface.

Key Features:

  • Visual badge-style tags with customizable colors and icons

  • Inline tag editor directly on Kanban cards

  • Multiple tags per ticket with icon and color support

  • Easy tag management without opening ticket detail view

  • Font Awesome 4 icon support for visual enhancement

Administrator Setup¶

Pre-installed Dynamic Field

The KanbanTags Dynamic Field is automatically created during the Kanban package installation or update. The field is pre-configured and ready to use - no manual field creation is required.

Note

The KanbanTags field is created automatically with the name KanbanTags and is available immediately after package installation. You can start configuring tags right away.

Accessing the KanbanTags Configuration

To configure or extend the available tags:

  1. Navigate to Admin → Dynamic Fields

  2. Locate the KanbanTags field in the Dynamic Fields list

  3. Click on the field name to open the configuration screen

Configuring Available Tags

In the Dynamic Field configuration screen, you can define the available tags that users can apply to their tickets:

For each tag, configure:

  • Value: The tag label text (e.g., Urgent, Bug, Feature)

  • Color: Hex color code for the badge background (e.g., #FF5733, #28A745)

  • Icon: Font Awesome 4 icon class (e.g., fa-bug, fa-star, fa-rocket)

Tip

Use the color picker to select colors visually, or enter hex codes directly for brand consistency.

Icon Selection

When adding or editing tags, you can select icons from the Font Awesome 4 library:

  • Start typing to filter available icons (e.g., type “bug” to find fa-bug)

  • Click on an icon to select it

  • Preview shows the icon with the selected color

Note

KanbanTags uses Font Awesome 4 Icons. Make sure to use the correct icon class names (e.g., fa-bug, not bug).

Saving Changes

  1. Click Save to apply your tag configuration

  2. The tags are immediately available on the Kanban board interface

  3. Users can start applying the configured tags to their tickets

Managing and Extending Tags¶

Adding New Tags to Existing Field

To add new tags or modify existing ones after the initial setup:

  1. Navigate to Admin → Dynamic Fields

  2. Find your KanbanTags field in the list

  3. Click on the field name to open the configuration screen

  1. In the tag configuration table, you can:

    • Add new tags: Click the + button to add a new row

    • Edit existing tags: Modify the Value, Color, or Icon directly in the table

    • Remove tags: Click the - (minus) button next to a tag

    • Reorder tags: Use drag-and-drop to change the display order

  2. Click Save to apply your changes

  3. The new tags are immediately available on the Kanban board and in ticket screens

Tip

When adding tags to an existing field, all previously assigned tags on tickets remain intact. New tags simply expand the available options.

Warning

Deleting tags: If you remove a tag that is currently assigned to tickets, those assignments will be preserved in the database but will no longer be visible in the tag editor. Only remove tags if you’re certain they are no longer in use.

Using KanbanTags in Ticket Screens¶

Dynamic Field Integration

KanbanTags fields work like standard Dynamic Fields and can be used in all ticket screens (create, edit, zoom, etc.). The field can be configured through the standard Dynamic Fields Screens interface in the Admin area.

Enabling in Ticket Screens

To make the KanbanTags field visible in ticket screens, use the Dynamic Fields Screens management:

  1. Navigate to Admin → Dynamic Fields

  2. Click on Dynamic Fields Screens in the left sidebar

  3. Select the screen where you want to enable the field (e.g., Default - AgentTicketNote)

  4. Find your KanbanTags field in the available fields list

  5. Set the display level using the WYSIWYG interface:

    • Disabled (unchecked) = Hidden from this screen

    • Enabled (checked) = Available on this screen

    • Required (required checkbox) = Mandatory field

The changes are applied immediately and the field becomes available in the selected ticket screens.

Note

Administrators familiar with OTOBO will recognize this as the standard process for managing Dynamic Field visibility across all ticket screens. No System Configuration changes are required.

Note

Two ways to manage tags:

  1. On Kanban Board: Quick inline editor for rapid tag changes

  2. In Ticket Screens: Standard Dynamic Field interface for detailed ticket editing

Both methods update the same field and stay synchronized.

Use Cases:

  • During Ticket Creation: Pre-assign tags when creating new tickets (e.g., Bug, High Priority)

  • During Ticket Processing: Add or remove tags as ticket progresses through workflow

  • In Ticket History: Tag changes are logged in ticket history for audit purposes

Tip

Enable KanbanTags in the AgentTicketZoom screen to allow agents to quickly add tags while reviewing ticket details, complementing the Kanban board editor.

Using KanbanTags on Kanban Cards¶

Opening the Tag Editor

On the Kanban board, each card displays the currently applied tags as colorful badges. To edit tags:

  1. Locate the tag section on a Kanban card

  2. Click on the tag badge area or the plus icon (if no tags are assigned)

  1. The inline tag editor modal opens

Tag Editor Interface

The tag editor modal consists of two sections:

  • Active Tags (top section): Currently assigned tags for this ticket

    • Click on a tag badge to remove it

    • Tags are displayed with their configured colors and icons

    • Scrollable container for many active tags

  • Available Tags (bottom section): All defined tags that can be added

    • Click on a tag badge to add it to the ticket

    • Only tags not already active are shown

    • Scrollable container for large tag collections

Adding Tags

  1. In the Available Tags section, click on any tag badge

  2. The tag instantly moves to the Active Tags section

  3. Changes are saved automatically

Removing Tags

  1. In the Active Tags section, click on any tag badge you want to remove

  2. The tag instantly moves back to the Available Tags section

  3. Changes are saved automatically

Keyboard Shortcuts

  • ESC: Close the tag editor modal

  • Click outside modal: Close the tag editor modal

Tip

Tag changes are saved automatically via AJAX - there’s no need to click a “Save” button or refresh the page.

Best Practices¶

Tag Organization

  • Limit tag count: Avoid creating too many tags (15-25 recommended for optimal usability)

  • Use clear names: Choose short, descriptive tag labels (e.g., Bug, P1, Review)

  • Color coding: Use consistent color schemes (e.g., red for urgent, green for completed)

  • Icon consistency: Use recognizable icons that match tag meaning

Color Recommendations

  • Status tags: Green (#28A745), Yellow (#FFC107), Red (#DC3545)

  • Priority tags: Red (#FF0000), Orange (#FF8C00), Blue (#007BFF)

  • Category tags: Use brand colors or distinct hues for easy visual scanning

Performance Considerations

  • KanbanTags are loaded efficiently using direct Dynamic Field queries

  • The tag editor uses AJAX for instant updates without page reload

  • Scrollable tag containers prevent UI issues with large tag collections

Note

KanbanTags values are stored as YAML in the Dynamic Field backend and support unlimited tag assignments per ticket.

User Guide¶

Kanban Board Layout Overview¶

  1. Boards Display: The top row displays the available boards.

  2. Quick Filters: Below the boards, there are flexibly configurable quick filters. The “My Tickets” filter is set as the default.

  3. Collapse Filters and Boards: Click on the triangle icon to collapse the filters and boards for a cleaner view.

Kanban Card Avatar¶

The avatar allows you to personalize tickets by selecting your image. To display the avatar, this feature must be enabled in the administration area.

Step-by-Step Guide:

Go to Gravatar’s Website: Visit Gravatar.com.

Sign In or Create an Account:

If you already have a WordPress.com account, you can log in with those credentials. If you don’t have an account, click on Create Your Gravatar and sign up using your email address. Verify Your Email: After signing up, you’ll receive a confirmation email. Open it and click the verification link to confirm your account.

Upload Your Picture:

Once logged in, click on Add a New Image. You can upload an image from your computer, take a photo using your webcam, or import one from a URL. Choose an Image Rating:

Gravatar allows you to rate your image based on its content (G, PG, R, X). Select an appropriate rating (most websites only accept G-rated images). Assign Your Image to an Email Address:

After uploading your image, assign it to your email address by selecting it from your profile. Finish: Your Gravatar image will now appear on any website that supports Gravatar when you use the assigned email address.

That’s it! You’ve successfully set up your Gravatar profile picture.
